# CS50W – Web Programming with Python and JavaScript

This repository contains my solutions, projects, and practice code developed while following **CS50’s Web Programming with Python and JavaScript (CS50W)**, a course offered by **Harvard University**.

The goal of this repository is both educational and demonstrative: to reinforce my understanding of modern web development concepts and to serve as part of my personal programming portfolio.

---

## 📚 Course Overview

CS50W builds on basic programming knowledge and focuses on the design and implementation of web applications using:

- Python
- Django
- JavaScript
- HTML & CSS
- SQL
- Git & GitHub

The course emphasizes real-world web development practices, including backend logic, frontend interactivity, and database-driven applications.
